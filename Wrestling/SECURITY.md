# Безопасность Wrestling

## Модель
Wrestling разделяет публичный каталог и пользовательские данные. Контент каталога читается без авторизации; прогресс, тренировки, аналитика, навыки и аккаунт требуют авторизации.

## Backend
- Go HTTP API с PostgreSQL.
- SQL-запросы параметризованы.
- Данные пользователя выбираются с ownership-предикатами.
- Миграции имеют SHA-256 checksum и не могут незаметно измениться после применения.
- PostgreSQL используется как source of truth для аккаунтов, прогресса и тренировочной истории.
- Транзакции применяются для создания и завершения тренировочных сессий.
- В БД есть ограничения длины, диапазонов и внешних ключей.

## Аутентификация
- Пароли хешируются bcrypt с cost 12.
- Пароль: 10–128 символов.
- Email нормализуется и проверяется через стандартный parser.
- Сессионный токен генерируется криптографически безопасным генератором.
- В БД хранится только SHA-256 digest токена.
- Сессии имеют срок действия и могут быть отозваны.
- Authenticated endpoints проверяют пользователя на каждом запросе.
- Auth responses не кэшируются.

## Защита HTTP
- request ID с ограничением длины и защитой от CR/LF.
- глобальный лимит тела запроса 2 MiB.
- отдельный более строгий rate limit для `/api/auth/*`.
- общий rate limit для публичного API.
- recovery middleware не позволяет panic уронить процесс.
- server read/write/idle timeouts.
- `X-Content-Type-Options`, CSP, HSTS, Referrer-Policy, Permissions-Policy, COOP/CORP и другие security headers.
- CORS работает по явному списку origins.
- `X-Forwarded-For` не считается доверенным без настройки trusted proxy.

## PostgreSQL
В продакшене необходимо:
1. использовать отдельную роль приложения с минимальными правами;
2. использовать уникальный сильный пароль/секрет;
3. включить TLS для подключения к БД;
4. регулярно делать backup и проверять restore;
5. ограничить сетевой доступ к PostgreSQL.

## Community
Пользовательский текст хранится как plain text и не рендерится как HTML. Видео принимаются только из YouTube после проверки URL. Есть комментарии и жалобы. Пользовательский контент должен рассматриваться как недоверенный.

## Домашние тренировки
Сайт не заменяет тренера или медицинскую оценку. Амплитудные броски, удушающие и болевые нельзя осваивать самостоятельно на неподготовленной поверхности. При боли, головокружении или плохом самочувствии тренировку следует прекратить.
