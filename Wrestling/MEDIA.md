# Wrestling — медиа для элементов

Для каждого элемента каталога подключены персональные ссылки на:

- поиск видео по точному английскому названию техники на YouTube;
- поиск фотографий/иллюстраций по названию техники в Google Images.

Это именно **навигация к материалам**, а не фиктивные прямые ссылки на несуществующие ролики. Проект не заявляет права на сторонние материалы. Для production можно заменить поисковые ссылки на проверенные видео/фото из легальных источников или собственного CDN без изменения модели `media`.
